# SELF-DEVELOPMENT DASHBOARD — NEXT.JS FRONTEND

Build a premium personal self-development dashboard using Next.js.

This is the FRONTEND PHASE ONLY.

Do NOT build the separate Node.js backend yet.

The application will eventually use:

* Next.js frontend
* Node.js backend in a separate repository
* Neon PostgreSQL database
* Raw SQL queries instead of Prisma

For this phase, focus on building the complete Next.js application, UI, UX, animations, dashboard architecture, pages, components, data models/interfaces, and frontend data layer.

---

# 1. PROJECT PURPOSE

This application is a personal self-development tracker.

The user logs their activities and progress every day across six major categories:

1. Communication
2. Expense
3. Food Routine
4. Skin Care
5. Study & Goals
6. Workout

The homepage should transform this daily information into a visual dashboard.

The user should be able to:

* Add daily information
* Track completed and pending tasks
* View daily progress
* View weekly progress
* View monthly progress
* View yearly progress
* Open a particular date
* See everything done on that date
* See everything still pending
* Track category-wise progress
* Track habits
* Track goals
* Track expenses
* See trends through charts
* Understand overall self-development progress at a glance

The application should feel like a personal progression system rather than a normal CRUD dashboard.
